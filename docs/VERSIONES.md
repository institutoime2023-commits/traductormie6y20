# Historial de versiones

## V0.1.0 — Base Android y prueba de micrófono

- Proyecto Android nativo Kotlin + Jetpack Compose.
- Identidad `com.orvex.traductor`.
- Pantalla principal inicial.
- Solicitud de permiso `RECORD_AUDIO`.
- Captura PCM16 mono a 16 kHz mientras la pantalla está visible.
- Indicador de nivel RMS.
- Sin grabación persistente, red ni modelos de IA.

## Próximos hitos

- V0.2: prueba de reconocimiento de voz local en el dispositivo.
- V0.3: traducción inglés → español.
- V0.4: TTS local con selección de voz.
- V0.5: audio continuo y salida Bluetooth.
- V0.6: cola de fragmentos, control de latencia y pruebas térmicas.
- V0.7: identidad, suscripciones y autorización.
